# Student Enrollment Form (SCHOOL-DB)

### Project Overview
This project is a **Student Enrollment Form** developed as a Micro Project. It is a web-based application designed for seamless student data management, featuring a clean UI and real-time database integration. 

The application is built using **HTML5**, **Bootstrap 3.4.1**, and **jQuery**, with **JsonPowerDB** as the high-performance backend storage engine.

---

### Key Features
*   **Primary Key Validation:** Uses **Roll-No** to uniquely identify and manage student records.
*   **Real-time Data Retrieval:** Instantly fetches existing student details if the Roll-No is found in the database.
*   **Dynamic UI States:** Automatically enables/disables form fields and buttons (Save/Update/Reset) based on the database status.
*   **Input Validation:** Ensures data integrity by preventing empty field submissions.

---

### Benefits of using JsonPowerDB
*   **Ultra-High Performance:** Built on a real-time indexing engine for lightning-fast CRUD operations.
*   **Schema-free:** Offers total flexibility without the need for predefined database structures.
*   **Serverless Support:** Eliminates the need for complex server-side code by using direct REST API calls.
*   **Low Maintenance:** Extremely easy to set up and manage compared to traditional SQL databases.
